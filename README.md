# 构建
###### 🐸 npm run build-frontend -- 构建dist
###### 🐸 npm run rd -- 移动前端静态资源，这个步骤是为了将前端的静态资源文件移动到正确的位置，以便后续打包使用 (rd命令会把 frontend/dist复制到 /public/dist ， 服务最终加载的是 /public/dist 前端资源)
###### 🐸 npm run move -- 并且根据需要进行配置，以确保资源被正确地移动到指定位置 (移动前端、配置等静态资源到指定目录，供生产环境使用。)
###### 🐸 npm run clean --清除加密代码
###### 🐸 npm run encrypt --代码加密
###### 🐸 npm run icon -- 生成应用程序的 Logo.


# 打包 安装包版
###### 🐸 npm run build-w：64位版本
###### 🐸 npm run build-w-32：32位版本
###### 🐸 npm run build-w-64：64位版本
###### 🐸 npm run build-w-arm64：arm64版本

###### 🐸 npm run build-wz-32：32位版本
###### 🐸 npm run build-wz-64：64位版本
###### 🐸 npm run build-wz-arm64：arm64版本
